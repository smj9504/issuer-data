# 미국 SEC EDGAR에서 가져올 수 있는 사전수요예측(Testing the Waters) 관련 공식 자료 조사

**Date:** 2026-08-10
**Status:** done

## Question

「국내 IPO 코너스톤 투자자 제도 도입 관련 당사 대응 전략 논의」 문서(2026-04-23 자본시장법 개정 관련)가 설명하는 미국 IPO 사전수요예측(Testing the Waters, TTW) 제도와 관련하여, 미국 SEC EDGAR에서 가져올 수 있는 공식 자료에는 어떤 것이 있는지 조사.

## 조사 범위

- 대상 제도: JOBS Act §5(d) (2012년 도입, 신생성장기업(EGC) 대상) 및 이를 전 발행사로 확대한 Rule 163B (2019년 채택, 2019-12-03 시행)
- SEC/EDGAR가 무료로 제공하는 공식 소스에 한정. 유료 서드파티 데이터 벤더(예: Renaissance Capital, Dealogic)는 조사 범위에서 제외.

## Method

**1차 조사(웹):** Rule 163B 원문 해설(법률사무소 메모: Willkie, Mayer Brown, Osler), DRS 비밀심사 절차 해설(Arnold & Porter, Greenberg Traurig, DFIN), 앵커투자자 "indication of interest" 공시 실무(Olshan), SEC EDGAR Full Text Search 공식 FAQ 등 2차 자료 조사.

**2차 검증:** 1차 조사의 핵심 주장 중 일부를 eCFR·Cornell LII의 법령 원문 및 SEC 공식 보도자료로 대조 확인. 전부를 재검증한 것은 아니며 항목별 검증 수준이 다름 — 자세한 내용과 한계는 아래 "현재 상태" 섹션 참고.

## 핵심 결론

**TTW 커뮤니케이션 원본 자료 자체는 EDGAR에 존재하지 않는다.** Rule 163B(17 CFR 230.163B)는 QIB·기관 적격투자자(IAI) 대상 TTW 커뮤니케이션을 증권법 §5(b)(1)·§5(c) 적용에서 면제하고, SEC 제출 의무도 없다(§230.424(a)·§230.497(a) 불요 — 원문 직접 확인함). 별도 표시(legend) 요건도 조문상 없음. TTW 커뮤니케이션이 Free Writing Prospectus 정의에서 제외되는 근거는 Rule 163B 자체가 아니라 별도인 Rule 405(정의 조항)이며, 이 조문도 직접 확인함. 즉 SEC는 발행사 내부 기록 보관만 전제할 뿐, 공시 자체를 요구하지 않는다 — 한국 개정 자본시장법 제119조의5(사전 정보제공 기록의 유지·관리 의무화)가 "기록"에 그치지 않고 향후 시행령에서 공시성 규제로 이어질지 여부와 대비되는 지점.

다만 TTW 전후 절차에서 발생하는 **간접·보완적 공식 자료**는 EDGAR에서 확인 가능하다.

## EDGAR에서 확인 가능한 공식 자료

| 자료 | 성격 | 활용 포인트 |
|---|---|---|
| **DRS / DRS/A** (비밀 심사용 초안 등록서) | JOBS Act(2012)로 EGC 대상 도입 → 2017년 전 발행사로 확대. 로드쇼 15일 전, 또는 로드쇼가 없으면 희망 발효일 15일 전까지 EDGAR에 **공개 전환**되어야 함 | 최초 DRS 제출일 → 최초 정식 등록서류(국내 발행사는 S-1, 외국민간발행인은 F-1) 공개일 간격 = 비밀 심사·사전 준비 기간의 프록시. 원문서 [그림2] "심사청구~증권신고서 제출" 구간과 대응 |
| **DRSLTR** | DRS 관련 커버레터 (공개 전환 시 함께 노출) | DRS 타임라인 보강 자료 |
| **CORRESP / UPLOAD** | SEC 심사역과의 서신 교환 기록 | UPLOAD(SEC→발행사)는 비공개인 경우가 많고, CORRESP(발행사→SEC)는 대부분 공개 |
| **S-1 / S-1/A 표지의 "Emerging Growth Company" 체크박스** | JOBS Act상 EGC 지위 자기신고 | TTW 관련 연혁 구분에 참고 (2019년 이후로는 TTW 이용 자격 자체와는 무관해짐 — 아래 "활용 시 유의점" 참고) |
| **S-1/A, 424B4의 "Testing-the-Waters Communications" 리스크팩터 섹션** | 문언 공시. TTW 진행 사실, 참여 QIB/IAI 인원수 등을 서술 (내용 자체는 비공개, "TTW를 했다"는 사실만 공시) | 원문서가 언급한 "NDR 빈도·범위 확대" 방향성의 실증 근거 |
| **"Indication of Interest"(앵커 투자자) 공시** — S-1/A·F-1/A·424B4 표지 및 인수 섹션 | 미국판 코너스톤에 가장 가까운 실무: 특정 투자자가 공모가로 특정 금액/수량 매입 의사를 표명했다는 사실을 프로스펙터스에 명시 (예: "entities affiliated with X have indicated an interest in purchasing up to $Y million of shares"). 프로스펙터스 표지의 공식 열거 항목(Item 501)에 포함된 건 아니고, SEC 심사 관행상 이의를 제기하지 않아(non-objection) 자리잡은 시장 관행에 가까움 | 이름·금액이 텍스트로 노출되는 경우가 많아 구조화 데이터로 정리 가능. 외국민간발행인은 S-1이 아닌 F-1/A에 같은 문구가 실리는 경우가 있어(Birkenstock 실사례) 국내·외국 발행사 서류를 함께 훑어야 함. 매칭된 문장 앞뒤로 기존 지분의 직접보유 전환, 상장 후 예상 지분율 등 더 중요한 맥락이 따라붙는 경우가 많아, 한 문장만 잘라내면 정보 손실이 큼 |
| **FWP (Free Writing Prospectus)** | TTW 자료 자체는 면제 대상이지만, 발행사가 로드쇼 자료 등을 자발적으로 FWP로 제출하는 경우 존재 | 보충적 신호 |
| **EDGAR 전문검색 (Full Text Search)** | 2001년 이후 전 제출서류 원문 검색, 무료·회원가입 불필요. 정확 문구·불리언 `OR`/`NOT`·`NEAR(n)` 근접검색·와일드카드(`단어*`) 지원(공식 FAQ로 확인함). 응답에 검색어 매칭 문서의 `form`·`file_date`·`file_description` 외에 `file_type`(EDGAR 자체 구조화 첨부문서 분류)·`display_names`(회사명+티커)도 포함됨(실제 쿼리 실행으로 확인함) | "indicated an interest", "qualified institutional buyers" 등 키워드로 신호 추출. **주의**: 단일 문구만으로는 선별력이 낮을 수 있음 — "testing-the-waters"는 2023년 S-1 필링만으로도 283건이 잡히는데 상위 히트 대부분이 인수계약서(Exhibit 1.1)의 정형화된 문구였음(실측). `file_type`이 "EX-1.1" 계열인 히트를 제외하는 식의 필터링이 사실상 필수 |
| **재무제표 구조화 데이터(XBRL)의 기업정보 항목** | 신생성장기업(EGC) 지위 등을 나타내는 불리언 값이 구조화 형태로 존재 | EGC 지위를 텍스트 검색 없이 구조화 데이터로 확인 가능 |

## 활용 시 유의점 — 항목별 TTW 관련성 강도

위 자료들을 실제로 추적·모니터링하는 체계를 만든다면, TTW와의 관련성 강도가 항목마다 다르다는 점을 감안해야 한다.

**직접 관련 — TTW 신호 자체를 포착**

- **전문검색 키워드 스캔** (`"indicated an interest"` / `"testing-the-waters"` 등): TTW는 제출 의무 자체가 면제되어 있어, EDGAR에 남는 유일한 흔적은 회사가 프로스펙터스에 "TTW를 했다"고 서술한 문장뿐이다. 이 문구를 정기적으로 스캔하는 것이 TTW 실시 여부·규모를 확인하는 가장 직접적인 방법.
- **앵커 투자자 확약 문장 추출**: TTW의 목적인 "사전 수요 확보"가 성공하면 특정 투자자의 확약 금액이 프로스펙터스에 명시되는데, 이것이 TTW의 실제 결과물이자 원문서의 코너스톤(사전 배정)과 가장 근접한 미국식 대응물이다 — 관련성이 가장 크다.

**간접(맥락) 관련 — TTW가 일어나는 시간대를 근사**

- **비공개 심사 기간 산출** (DRS 최초 제출일 ~ 등록서류 최초 공개일): TTW 내용 자체는 담지 못하지만, TTW가 실제로 일어날 수 있는 시간 창(window)을 근사한다 — 원문서 [그림2]가 "① 미국 TTW 제도"를 주관계약 체결~심사청구 구간에 배치한 것과 같은 맥락.

**관련성 약함 — 사실상 별개 축**

- **EGC 지위 확인**: 2012년 JOBS Act 도입 당시엔 TTW가 EGC 전용이었지만, 2019년 Rule 163B로 전 발행사로 확대되어 지금은 EGC 여부가 TTW 이용 자격과 무관하다. TTW 조사라는 목적만 놓고 보면 우선순위가 낮고, 발행사 프로필을 구분하는 부가 변수 정도로 보는 것이 정확하다.

## 현재 상태 (2026-08-11 기준)

실제 데이터 수집 로직으로 구현되어 있으며, 최근 미국 IPO 5건(CAVA, Instacart, Klaviyo, Reddit, Birkenstock)의 실제 SEC 공시와 SEC 1차 자료로 검증된 상태 기준.

### 되는 것

**신호 수집 (5종)**
- **가격밴드 신호**: S-1/S-1-A(국내) 또는 F-1/F-1-A(외국민간발행인) + 424B* 문서를 스캔해 IPO 확정가가 희망밴드 대비 몇 % 위/아래인지 산출. 5건 모두 실제 공개된 IPO 조건과 일치(CAVA +16%, Instacart +7%, Klaviyo +11%, Reddit +0%, Birkenstock -6%).
- **비공개 심사 기간 신호**: DRS/DRS-A 최초 제출일 → 최초 공개 등록서류(S-1 또는 F-1) 공개일 간격. 국내·외국 발행사 둘 다 지원. 실측값 67일(Birkenstock)~798일(Reddit)까지 확인.
- **앵커 투자자 신호**: 투자자명·확약 금액을 정규식으로 추출하고, 매칭 문장 앞뒤 맥락(기존 지분의 직접보유 전환, 상장 후 예상 지분율 등)까지 포함해서 저장. 같은 문서 안에 여러 투자자가 나오거나 여러 amendment에 걸쳐 반복 공시되는 경우도 정상 처리(중복 없이, 서로 다른 투자자는 안 지워짐). Birkenstock의 Financière Agache($325M, LVMH 아르노 가문) 사례로 확인.
- **"oversubscribed" 전문검색 신호, Nasdaq IPO 캘린더 신호**: 기존부터 동작.

**EDGAR 전문검색(EFTS) API**
- `efts.sec.gov`에 API용 User-Agent(`앱이름 연락처이메일` 형식)로 정상 호출됨 — 실제 쿼리 실행으로 확인(`"testing-the-waters"` + `forms=S-1` + 2023년 조건, HTTP 200, 283건).
- 검색 문법 — 정확 문구(따옴표), 불리언 `OR`/`NOT`, `NEAR(n)` 근접검색, 와일드카드(`단어*`) 전부 SEC 공식 FAQ로 지원 확인.
- 응답 필드 — `ciks`·`form`·`file_date`·`file_description` 외에 `file_type`(EDGAR 자체 구조화 첨부문서 분류)·`display_names`(회사명+티커)·`_score`(관련도) 등도 실제 raw 응답으로 확인. `file_type` 우선 + `file_description` 폴백으로 인수계약서(EX-1.x) 제외 필터링 구현 완료.
- **페이지네이션**: `from` 파라미터로 결과 오프셋 이동이 실제로 됨을 확인 — 동일 검색(total 5551건 고정)에서 `from` 유무에 따라 다른 결과셋이 반환됨.
- **에러 처리**: HTTP 상태 코드가 아니라 **200 OK 응답 안의 `"error"` 키**로 에러를 표시함 — 예: 빈 쿼리(`q=""`) 시 `{"error": "Blank search not valid...", "hits": {"hits": []}}`. `q` 파라미터를 아예 생략하면 에러 없이 전체 필링을 최신순으로 반환(빈 문자열과는 다른 동작) — 전부 실제 호출로 확인.
- SEC.gov 일반 웹페이지(보도자료, FAQ)도 같은 방식의 User-Agent로 정상 접근 — 이번 조사에서 실제로 열람함.

**규정 근거 (1차 자료 직접 확인)**
- Rule 163B(17 CFR 230.163B): SEC 제출 의무 없음, 레전드 요건 없음, 전 발행사 적용 — eCFR·Cornell LII 원문 + SEC 자체 2019-09-26 보도자료로 확인.
- Rule 405(17 CFR 230.405)의 FWP(Free Writing Prospectus) 정의: "A written communication used in reliance on Rule 163B (§ 230.163B) or on section 5(d) of the Act"를 FWP 정의에서 명시적으로 제외한다는 조문을 Cornell LII 원문으로 직접 확인 — TTW 통신이 FWP 정의에서 빠지는 근거가 Rule 163B 자체가 아니라 Rule 405라는 서술이 맞았음을 확인함.
- Rule 163B 시행일: Federal Register 문서번호 2019-21304(2019-10-04 게재)를 확인 — 게재일 + 60일 = 2019-12-03으로, 위 "핵심 결론"의 시행일 서술과 정확히 일치함.
- Reg S-K Item 501(17 CFR 229.501): 앵커 투자자 공시가 공식 열거 항목이 아니라 SEC 심사 관행(non-objection)에 근거한다는 점 확인.
- DRS 비공개 제출 범위가 **2025-03-03**부터 IPO 중심에서 사실상 모든 증권법상 공모 + 거래소법 §12(b)/§12(g) 등록으로 확대됐음을 다수 로펌 자료(Willkie, Morrison Foerster, Sullivan & Cromwell 등)로 확인 — 원 조사가 참고한 2019년 시점 해설엔 없던 내용. 본 조사가 다루는 "IPO 맥락의 DRS→최초 등록서류 공개" 신호 자체에는 영향 없음.

### 안 되는 것 / 한계

**구조적 한계 (데이터가 원천적으로 없음)**
- TTW 커뮤니케이션 원본 자체는 EDGAR 어디에도 없음 — Rule 163B가 SEC 제출 자체를 면제하기 때문. 수집 방식의 문제가 아니라 제도 자체의 한계.

**신호 품질 한계**
- **TTW 전문검색 신호는 선별력이 낮음.** "testing-the-waters" 단일 문구는 2023년 S-1 필링만으로도 283건이 잡히고, 그중 대부분(실측 상위 히트 전부)이 인수계약서(Exhibit 1.1)의 정형화된 규정 준수 문구 — 실질적 TTW 서술이 아님. `file_type` 기반으로 이 출처를 제외해도, 그 결과 **대부분의 회사에서 0건이 나오는 게 정상 동작**(TTW 자체가 비공시 대상이므로) — 즉 "TTW를 실질적으로 서술한 회사"를 찾는 용도로는 여전히 약한 신호.

**여전히 미확인 (공식 문서 자체가 없음 — 실측으로도 한계가 있음)**
- **EFTS 응답 JSON의 "전체" 필드 목록·`from`/`q`/`forms` 외 다른 파라미터(예: `size`, 정렬 옵션)·에러 케이스 전체 목록**: SEC 공식 문서에 없음. 지금까지 확인한 것 — 필드 목록(`ciks`/`form`/`file_description`/`file_date`/`file_type`/`display_names`/`root_forms`/`biz_states`/`inc_states`/`sics`/`film_num`/`file_num`/`_score`), `from` 페이지네이션 동작, 에러가 200 OK 안 `"error"` 키로 옴 — 은 전부 실제 호출로 역공학한 것이지 SEC가 문서로 보장한 계약이 아니므로, 예고 없이 바뀔 수 있음.
- **코드가 아직 처리하지 않는 부분**: 위에서 확인한 `"error"` 키를 현재 코드(`_edgar_fulltext_signal`)는 확인하지 않음 — 다만 이 코드가 쓰는 쿼리(`"oversubscribed"`, `"testing-the-waters"`)는 항상 비어있지 않은 고정 문자열이라, "빈 쿼리" 에러 케이스가 실제로 발생할 상황 자체가 없어 지금 당장의 영향은 없는 이론적 갭임.

**일반 한계**
- 법률 자문이 아닌 데이터 소스 조사. 실제 의사결정 전에는 자체 법률 검토 필요.
